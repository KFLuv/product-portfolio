## 这个项目在作品集里的作用

我在作品集里的其他项目大多是 **AI 方向**，而且都是我自己发现需求做出来的。

**但它们有一个共同的问题：我是产品和开发同一个人，所以需求侧的过程被跳过了。**

这个课程项目正好补上那块：

| 它证明什么 | 怎么证明 |
|---|---|
| **能从零定义需求边界** | 三端（客户端 / 商家端 / 管理端）功能边界清晰、无冗余功能 |
| **能画业务流程** | 用户查找流程、商家申请与审核流程（**含驳回回路**） |
| **能画系统模块图** | 三端各自的四层模块结构 |
| **能产出可评审的交互原型** | **界面原型 9 张，覆盖三端全流程** |

> **一句话**：这个项目证明我走完了「需求 → 流程 → 原型」的完整产品设计链路。
