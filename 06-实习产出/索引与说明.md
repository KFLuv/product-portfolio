## 一、产品选型（最完整的一块）⭐

这段实习里我独立完成过一次**企业大学平台选型**，产出物是产品岗的典型交付。

### 建筑检测集团企业大学平台选型

| 产物 | 说明 |
|---|---|
| **选型完整调研报告** | 305 行，含需求梳理、候选供应商、对比维度、结论建议 |
| **综合汇总文档** | 301 行，补齐表格板块 |
| **供应商对比技术方案报告** | 234 行，含 4 家厂商对比（新增企学宝） |
| **单厂商深度调研（PlayEdu）** | 96 行，产品能力与适配性分析 |
| **对标调研清单（LMS）** | 72 行，对标领课网络 |

**选型的核心方法（我在实习里形成的）：**

| 步骤 | 我做了什么 |
|---|---|
| 1. 需求先行 | 先定义"我们要解决什么问题"，而不是先看厂商有什么功能 |
| 2. 维度统一 | 所有厂商用**同一套对比维度**打分，不做"各家亮点罗列" |
| 3. 落地视角 | 不只比功能，还比**部署方式、数据归属、后期维护成本** |
| 4. 给结论 | 输出**推荐报告**，而不是把选择题丢回给领导 |

> **结果**：选型结果**已被客户采纳**，支撑了采购决策。

```
□ 内网 IP      192.168.x.x / 10.x.x.x / 172.16-31.x.x
□ 真实域名     客户域名 等客户域名
□ 账号密码     任何明文凭据
□ 手机号       1[3-9]xxxxxxxxx
□ 身份证号
□ 客户名称     泛化为"某建筑检测集团""某校园项目"
```
